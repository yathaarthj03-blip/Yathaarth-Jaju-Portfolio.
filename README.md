## 👋 What is this?

This is the source code of my personal portfolio, the place where my work, my stack and my story live in one scroll.

I'm **Yathaarth**, a 19-year-old founder from Mumbai. I study commerce by day and build with code by night. Most developers don't understand business, and most business people don't understand code, so I work on the bridge between the two.

> *"Numbers tell me where the money is. Code lets me go get it."*

## 🏃 Run it locally

```bash

# jump in
cd Yathaarth-Jaju-Portfolio

# open index.html in your browser, or serve it locally
npx serve .
```
